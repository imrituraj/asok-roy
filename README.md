# asok-roy

Portfolio website for **Asok Roy** — brick manufacturer (Maa Bricks Industries, Jirania) and government contractor from Sonamura, Tripura. Bilingual: English / বাংলা.

Built with React + Vite.

```bash
npm install
npm run dev
```

## Editing content

Everything editable lives in [`src/data.js`](src/data.js):

- **Contact** — phone, WhatsApp, email (buttons appear once filled in)
- **Photos** — drop a file in `public/photos/` and add one line to the `photos` list
- **Copy** — all English and Bengali text
